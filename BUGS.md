# Отслеживание исправлений багов и недоработок (Bug Tracker)

Данный документ содержит список выявленных в ходе аудита багов, недоработок и граничных случаев в проекте PeerChecker. Статус исправления отслеживается с помощью полей `[ ]` (не исправлено) и `[x]` (исправлено).

## Список багов

- [x] **[BUG-01] Утечка соединений SQLite из-за отсутствия `conn.close()`**
  - **Компонент:** `app/storage.py`
  - **Описание:** Контекстный менеджер `with self._get_connection() as conn:` управлял транзакцией, но не закрывал соединение `sqlite3.Connection`. Добавлен контекстный менеджер `connection_scope()`, явно закрывающий соединение во всех операциях БД.

- [x] **[BUG-02] Ошибка разметки Telegram Markdown (v1) при `first_seen` == None**
  - **Компонент:** `app/bot.py`
  - **Описание:** При вызове `escape_markdown(peer.get('first_seen'))` для несуществующего или пустого значения `first_seen` возвращалась пустая строка, образуя невалидные бэктики `` `` `` в Markdown v1. Исправлено добавлением дефолтного значения `"Неизвестно"`.

- [x] **[BUG-03] Гонка потоков (Race Condition) при перезапуске фонового мониторинга**
  - **Компонент:** `app/bot.py`
  - **Описание:** Вызов `/start_monitoring` сбрасывал `stop_event` ДО завершения старого потока. Исправлено вызовом `join()` старого потока при перезапуске и проверкой `self.monitoring_thread == current_t` в цикле `_monitoring_loop`.

- [x] **[BUG-04] Некорректное строковое представление отсутствующего `className` у пира**
  - **Компонент:** `app/validator.py`
  - **Описание:** При отсутствии атрибута `className` у пира в лог и детали записывалось `'None'`. Добавлено форматирование отсутствующего класс-нейма в понятную строку `"Не указана"`.

- [x] **[BUG-05] Утечка сокетов `requests.Session` при вызовах OpenAPI**
  - **Компонент:** `app/s21_api.py`
  - **Описание:** Экземпляр `S21ApiClient` не имел метода `close()`. В `S21ApiClient` добавлены метод `close()` и поддержка контекстного менеджера (`__enter__`/`__exit__`), а в `run_check_and_notify` клиент обернут в контекстный менеджер.

- [x] **[BUG-06] Избыточный повторный вызов при обработке 401 Unauthorized в `_request`**
  - **Компонент:** `app/s21_api.py`
  - **Описание:** Проведен рефакторинг логики обновления токена при получении HTTP 401 в `_request` с поддержкой единообразной обработки повторов.

- [x] **[BUG-07] Небезопасное вычисление времени жизни токена `expires_in`**
  - **Компонент:** `app/s21_api.py`
  - **Описание:** При явной передаче `"expires_in": null` от Keycloak происходила ошибка `TypeError`. Добавлена безопасная обработка `expires_in_val = float(raw_expires) if raw_expires is not None else 300.0` и динамический выбор буферного времени.

- [x] **[BUG-08] Отсутствие безопасного разбиения длинных сообщений Telegram (>4096 символов)**
  - **Компонент:** `app/bot.py`
  - **Описание:** При отправке длинного отчета сообщения могли превысить лимит Telegram 4096 символов. Добавлена функция `chunk_text()`, разбивающая сообщения на безопасные фрагменты до 4000 символов.

- [x] **[BUG-09] Отсутствие юнит-тестов для граничных случаев и утечек ресурсов**
  - **Компонент:** `tests/`
  - **Описание:** В тестовый набор добавлены юнит-тесты `test_storage_connection_closed`, `test_peer_card_null_first_seen`, `test_chunk_text`, `test_authenticate_null_expires_in`, `test_s21_api_context_manager`, `test_validate_peer_none_class_name`.
